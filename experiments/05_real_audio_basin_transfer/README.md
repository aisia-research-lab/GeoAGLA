# 05. Real Audio Basin Transfer Experiments

Scripts evaluating basin geometry, initial phase distance, and convergence behaviors on real speech, music, and noise audio waveforms:
- `01_phase2a_synthetic_transfer.py`: Synthetic waveform transfer and edge tracking.
- `02_phase2a_wav_transfer.py`: Real WAV audio evaluation.
- `03_phase2b_real_audio_basin_sweep.py`: Basin profile and initialization distance sweeps.
- `04_real_audio_multi_sample_validation.py`: Multi-sample validation across diverse acoustic categories.
