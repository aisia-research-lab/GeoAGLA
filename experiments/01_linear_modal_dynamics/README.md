# 01. Linear Modal Dynamics & Spectral Analysis (Phase 1B)

This directory contains standalone reproduction scripts for the linear modal dynamics and asymptotic spectrum of Phase Retrieval operators:
- `01_s0_linear_modal_dynamics.py`: Linearization around stationary points, verification of neutral modes (lambda=1), and eigenvalue spectrum decomposition.
- `02_h1_geometry_spectral_correspondence.py`: Empirical verification that the sub-dominant eigenvalue lambda_2 controls asymptotic local contraction.
- `03_h2_oracle_rate_prediction.py`: Comparison of theoretical asymptotic contraction rates q_oracle against empirical per-iteration contraction.
